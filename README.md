# RiskLab Charts

This repo contains the `@risklab/charts` package and the standalone chart adapter packages.

## Packages

- `@risklab/charts`
- `@risklab/charts-react`
- `@risklab/charts-vanilla`
- `@risklab/charts-vue`
- `@risklab/charts-svelte`
- `@risklab/charts-angular`
- `@risklab/charts-lit`
- `@risklab/charts-solid`

## Install

Core only:

```bash
npm install @risklab/charts
```

Framework adapter:

```bash
npm install @risklab/charts @risklab/charts-react
```

## Repo Commands

```bash
npm run validate
npm run build:all
npm run pack:all
npm run smoke:install
```
